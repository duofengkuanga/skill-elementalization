# 09 — 应用完整元素视觉与可访问性

**What to build:** 用户获得一套克制、原生且可辨识的 CoolSkill 视觉体验，包括自定义四元素图标、主题色、浅深模式、动效和完整辅助功能语义。

**Blocked by:** 03 — 允许用户永久修改元素归属; 07 — 支持临时面板、Pinned 与 Spaces.

**Status:** done

- [x] 左侧只显示四枚统一语言的自定义图标，不显示元素单字。
- [x] 风、火、水、山分别使用青绿、朱红橙、蓝、岩金主题色。
- [x] 界面跟随系统浅深模式并保持足够对比度。
- [x] 元素切换使用 180–240ms 专属动效，Reduce Motion 时退化为淡入。
- [x] 无持续空闲动画，图标和交互具有辅助功能标签。
- [x] 主列表使用无常驻底色的紧凑名称/次数行，描述只在悬停详情出现。
- [x] App 与菜单栏图标保留 🌈 造型，限定火/山/风/水四道色带，四元素导航不变。
