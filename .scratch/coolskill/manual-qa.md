# CoolSkill V1 手工验收

以下手工项目由用户在 Apple Silicon Mac、macOS 15+ 与真实 Codex Desktop 上完成。系统权限由用户自行处理。

## 启动与面板

- [ ] 运行 `Scripts/build-app.sh` 后，`.build/CoolSkill.app` 可从 Finder 或 `open` 启动，并显示 Dock 图标与技能库主窗口。
- [ ] 启动时不默认展开任何元素；悬停或点击左侧图标后显示对应 Skill 列表。
- [ ] 顶部“更新 Skills”会重扫 `~/.agents/skills`；左侧栏底部 Pin 可切换窗口置顶。

## Skill 目录与视觉

- [ ] 更新后只显示 `~/.agents/skills` 中的 Skills；清空来源目录后不保留旧列表。
- [ ] 悬停四枚元素图标会切换列表，鼠标移入列表时不会意外切换。
- [ ] Skill 行只显示名称和非零次数，无默认第一行高亮；描述在悬停详情中查看。
- [ ] 详情浮层、右键移动和拖拽移动均可用；重启后人工元素保持。
- [ ] 浅色、深色与 Reduce Motion 行为符合 spec。

## 快捷键与窗口

- [ ] 用户授权键盘监听后，`Command + D + P` 在 150ms 内呼出鼠标附近面板。
- [ ] 单独 `Command + D` 只产生可接受的短延迟，原应用仍收到一次且仅一次。
- [ ] 1–4、方向键、Return、Escape 和重复全局组合行为正确。
- [ ] 临时面板在屏幕边缘不会越界，外部点击会关闭。
- [ ] Pinned 面板可调整尺寸、成功插入后保持、固定在当前 Space，重启后不恢复 Pin。
- [ ] Pinned 后切换 Space，再按快捷键会出现额外临时面板而不移动原面板。

## Codex 插入

- [ ] 用户授权辅助功能后，空输入框可插入 `$skill-name `。
- [ ] 中文、Unicode、多行、行中光标和选中文本均保持原内容，插入位置与空格正确。
- [ ] CoolSkill 不写入浏览器、终端、编辑器或只读控件。
- [ ] 没有聚焦 Codex composer 时面板保持并显示中文恢复提示。
- [ ] Codex 位于另一个 Space 时，点击 Skill 会立即切至 Codex，并在该窗口可写入后完成注入。
- [ ] 插入不会改变系统剪贴板。

## 使用统计与恢复

- [ ] 首次全历史统计在后台运行，面板浏览不被阻塞。
- [ ] 后续增量刷新快速完成；显式、自动和子代理调用可在重建后反映。
- [ ] 损坏 Skill、损坏相关 rollout 和损坏 CoolSkill 状态会显示可恢复提示。
- [ ] 重建统计不删除人工元素；清除本地数据需二次确认且不修改 Skill/Codex 文件。
